# Nilsagor FM Hub — Clean Native Android Starter

This is a clean native Jetpack Compose Android project designed for GitHub Actions.

- Package: com.nilsagorfmhub.app
- Android: min 24 / target 35
- Java/Kotlin JVM target: 17
- No Firebase or external icon dependency in this starter
- GitHub Actions builds a debug APK

After the first successful APK build, Firebase login, admin settings, radio URL and community backend can be added safely.
